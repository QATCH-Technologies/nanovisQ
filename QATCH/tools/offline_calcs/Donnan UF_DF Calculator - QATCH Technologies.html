About This Model

This tool is an open Donnan/UF/DF screening model based on a simplified version of:

Kannan et al., Predicting Formulation Conditions During Ultrafiltration and Dilution to Drug Substance Using a Donnan Model with Homology-Model Based Protein Charge, J. Pharmaceutical Sciences, 112 (2023). doi:10.1016/j.xphs.2022.10.028

This is not the original Kannan model and should be considered an approximate educational / screening implementation.

What the model estimates
  • Buffer concentration shifts across the UF/DF membrane
  • Ionic redistribution of charged species
  • Approximate pH changes during UF/DF
Supported components
  • Histidine — weak buffer (Henderson–Hasselbalch)
  • Acetate — weak buffer (Henderson–Hasselbalch)
  • Arginine
  • NaCl

Counterions may be automatically added internally to maintain electroneutrality.

Protein charge input
  • Direct Z and dZ/dpH (preferred) — can be estimated from sequence data using the tools below.
  • Estimated from pI and protein type — mAb, Fab, generic, and polyclonal options are simplified heuristics not in the original paper.
Free charge estimation tools
  • Protpi Protein Tool
  • ExPASy ProtParam
  • PROPKA
Simplifications vs. original paper
  • Protein charge
  • Buffer thermodynamics
  • Donnan equilibrium
  • Ionic strength / activity corrections
  • Molecular structure effects
